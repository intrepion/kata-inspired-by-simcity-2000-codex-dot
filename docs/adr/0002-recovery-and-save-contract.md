# Recoverable treasury and versioned saves

A negative treasury freezes construction, not demolition or time. One interest-free $3,000 recovery grant is available below $500. Taxes and free demolition remain usable after the grant, and an empty city has no expenses. If the grant is exhausted, removing every built tile allows $3,000 fresh-start relief next month, so even extreme debt remains recoverable. There is no irreversible game-over softlock. A strict versioned local save rejects malformed, impossible, or foreign terrain without replacing the current city. Imported saves are files, not network uploads.
